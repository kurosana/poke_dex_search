# デザイン要件定義書

対象: `PokeDexSearchTool_PC.py` の見た目を、Web 上で「Windows の Tkinter デスクトップアプリ」として再現する。

原典はクラシック Tk ウィジェット（Label / Entry / Button / Menu）と ttk ウィジェット（Treeview / Scrollbar）の混在である。モダンな Web デザイン（カード、マテリアル、ポケモン公式風の赤図鑑 UI）にはしない。

---

## 1. 全体のトーン

- デスクトップアプリのウィンドウが、無地のデスクトップの上に載っている。
- 配色は Windows の Tk 既定に合わせる。
  - ウィンドウ内背景: `#f0f0f0`（SystemButtonFace）
  - 文字: `#000000`
  - 入力欄背景: `#ffffff`
  - リスト背景: `#ffffff`
  - リスト選択: `#0078d7`、文字は白
  - 詳細ハイライト: `#cefff8`（原典 `tag_configure('highlight', background="#cefff8")`）
- フォントは日本語 Windows の Tk 既定に近づける。
  - `"Yu Gothic UI", "Meiryo UI", "Yu Gothic", Meiryo, "Segoe UI", sans-serif`
  - サイズ 9pt（12px）
- カーソルは Web の pointer ではなく、Tk 同様 **既定矢印**（入力欄のみ I ビーム）。

## 2. メインウィンドウ

### 2.1 ウィンドウ枠

- タイトルバー文言: `Pokedex Search`（原典 `master.title`）
- タイトルバーは Windows の通常ウィンドウに見せる（薄いバー、タイトル左寄せ、閉じるボタン）
- 起動時サイズ: コンテンツ基準でコンパクト。Treeview 相当がおおよそ 10 行見える高さ。幅はおおよそ 420px 前後。
- リサイズ可能。中の一覧だけが伸びる。

### 2.2 配置（pack の再現）

原典は上から `pack()` している。余白はほぼ無し。横方向は中央寄せ。

上から順:

1. ラベル `ポケモン名or検索したい単語:`（中央、自然幅）
2. テキスト入力（中央、幅およそ 20 文字。Tk `Entry` 既定幅）
3. ボタン `単語検索`（中央、ラベル幅に合わせた小さめの立体ボタン）
4. 一覧（横いっぱい、残り高さを占有）
5. 縦スクロールバーは一覧の右端

ラベル・入力・ボタンの下に大きな余白やカード枠を置かない。Tk の「殺風景な灰ウィンドウ」そのものにする。

### 2.3 入力欄

- 白背景、沈み込み（inset）の 2px ボーダー
- フォーカス時も華美なアウトラインを付けない（黒いフォーカス枠程度）
- プレースホルダ文言は出さない（原典に無い）

### 2.4 ボタン

- 灰背景 `#f0f0f0`
- 浮き上がりボーダー（上左が明るく、下右が暗い）
- 押下中はボーダーが逆（沈む）
- ホバーで色を変えない
- 角丸にしない

### 2.5 一覧（Treeview）

- 見出し行が 1 つだけ: `ポケモン名(ダブルクリックで詳細)`
- `show='headings'` 相当で、ツリーの開閉アイコン列は出さない
- 見出しは薄いグレー、1px 境界、中央ではなく左寄りの見出し文字
- 行の高さは約 20px、横線は薄いまたは無し（ttk 既定に近い）
- 選択行は単一選択、青背景・白文字
- ホバーハイライトは付けない（ttk 既定に無い）
- ゼebra ストライプは付けない
- 空の初期状態では見出しと空白の本体だけ

### 2.6 スクロールバー

- 縦のみ
- 一覧の右に常時配置
- OS 標準のスクロールバーでよい

## 3. 詳細ウィンドウ

### 3.1 ウィンドウ

- タイトル: `{ポケモン名} の詳細`
- クライアントサイズ **800 × 400**（原典 `geometry("800x400")`）
- メインとは別ウィンドウ。モーダルでメインをロックしない
- 閉じるボタンでそのウィンドウだけ閉じる
- 複数同時に開いて重なる。後から開いた／クリックした方が前面
- タイトルバーを掴んで移動できる（OS の Toplevel 相当）

### 3.2 テーブル

- 見出し: `バージョン` / `説明`
- 列幅の初期値: バージョン 100px、説明 600px（残りは説明側が使う）
- 行が多いときは縦スクロール
- ハイライト行の背景 `#cefff8`
- 選択中の行はハイライトより選択色を優先（青背景・白文字）。選択を外すとミント背景に戻る

### 3.3 右クリックメニュー

- クラシックな白背景の小さいメニュー
- 項目は 1 つ: `コピー(Ctrl+C)`
- tearoff（点線でメニューを切り離す機能）は出さない
- 影付きの単純な矩形。角丸やアイコンは付けない

## 4. ページ（GitHub Pages）側の枠

アプリ本体以外の装飾は最小限にする。

- ブラウザのタブタイトルも `Pokedex Search`
- ページ背景はデスクトップを思わせる無地のグレー
- ヒーロー画像、ポケモン公式カラー、検索サイト風の大きな検索ボックスは置かない
- 説明文やヘルプをメインウィンドウの中に足さない（原典のウィンドウ内にヘルプは無い）

README や要件定義書へのリンクが必要なら、ウィンドウの外（ページ下部）に小さく置く。アプリの見た目とは分離する。

## 5. 状態の見た目

| 状態 | 見た目 |
| --- | --- |
| 起動直後 | 一覧は空（メッセージも出さない） |
| 検索ヒット | ポケモン名が行として並ぶ |
| 0 件 | メッセージ 1 行。特別なエラー色にはしない（通常行と同じ） |
| 詳細の該当説明 | `#cefff8` |
| データ読み込み中 | 入力・ボタンはまだ使えても結果は出ない。大きなスピナーは出さない |
| 読み込み失敗 | 一覧に短い失敗メッセージ |

## 6. やってはいけないデザイン変更

- 角丸カード、ドロップシャドウの検索ボックス、大きなプライマリボタン
- ポケモンタイプ色やスプライト画像の追加
- ダークモード
- 一覧に図鑑番号・タイプ・ゲーム名を足す
- ハイライト色を `#cefff8` 以外にする
